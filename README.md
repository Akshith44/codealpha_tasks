# CodeAlpha Task 1 - Simple E-commerce Store

Full-stack project for the CodeAlpha Full Stack Development Internship.

## Features
- Product listing
- Product search and category filter
- Product details page
- Shopping cart
- User registration and login
- JWT authentication
- MongoDB database
- Order checkout and order history
- Responsive frontend
- Node.js + Express backend

## Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB + Mongoose
Authentication: JWT + bcryptjs

## Run
1. Install Node.js LTS and MongoDB.
2. Open this folder in VS Code.
3. Open terminal:
   npm install
4. Copy `.env.example` to `.env`.
5. Start MongoDB locally.
6. Run:
   npm run seed
7. Start:
   npm run dev
8. Open:
   http://localhost:5000

## Important
This demo does not process real payments. Checkout creates an order in MongoDB.
